# Tic-Tac-Toe

A simple two-player Tic-Tac-Toe game built using only HTML, CSS, and JavaScript.

## Files
- index.html - Game structure
- style.css - Game design
- script.js - Game logic

## How to Run
1. Clone or download this repository.
2. Open index.html in a web browser.
3. Start playing.

## How to Play
1. Player X starts.
2. Players take turns clicking an empty square.
3. Get three matching symbols in a row, column, or diagonal to win.
4. If all squares are filled without a winner, the game is a draw.
5. Click Restart Game to play again.

## Technologies
HTML5, CSS3, JavaScript
